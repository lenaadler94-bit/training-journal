# Твой человек

Я занимаюсь тренировками нескольких направлений (типов) и веду журнал в Obsidian. Направления:
- **Холодовой тренинг** (cold training) — зимнее плавание и аналоги.
- **Функциональные тренировки** (functional) — различаются по видам: табата, круговая, интервальная, статика и другие. Вид указывается явно.
- **Бег** (running) — помимо самого бега может включать блоки **СБУ** (специальные беговые упражнения) и **ОФП** (общая физическая подготовка). Параметры: темп, километраж, зоны пульса и т.д. **Покрытие:** асфальт (по умолчанию, можно не указывать), трейл — указывается отдельно.
- **Йога** (yoga) — различается по видам, вид можно не указывать.
- **Плавание** (swimming) и другие направления.

Опыт детальный: я знаю терминологию (СБУ/ОФП, зоны пульса, трейл/асфальт, табата/круговая/интервальная/статика), мне не нужно разжёвывать базу.

# Проекты

Рабочий проект — личный журнал тренировок в Obsidian-vault. Цель: вести и структурировать записи о тренировках, отслеживать состояние и прогресс. Со временем подключатся skills и, при необходимости, субагенты.

# Как работаем

- При новой записи тренировки: фиксируй **только то, что я говорю**. Не добавляй параметры, цифры, оценки, которых я не назвал. Пустые поля оставляй пустыми.
- Если в моих словах чего-то не хватает для записи (например, я назвал тип, но не сказал дату или объём) — **задай уточняющий вопрос** перед тем как записывать.
- Перед значимыми действиями (создание новой папки, нового шаблона, переименование существующего файла) — показывай, что собираешься сделать, и жди подтверждения.
- Проверка результата: коротко перечисляй созданные/изменённые файлы. Отдельный отчёт не нужен, если не прошу.

# Чего не делать

**Границы (без явного разрешения):**
- Не удалять файлы.
- Не переименовывать файлы.
- Не выходить за пределы рабочей директории проекта.
- Не отправлять сообщения во внешние системы.

**Анти-паттерны:**
- Без длинных вступлений — сразу к делу.
- Без избыточных эмоций и смайликов. Тон спокойный, дружелюбный, по делу.
- Не пересказывать то, что я только что сказал или что видно в изменённых файлах.

# Частые задачи

- **Записать тренировку.** Создать markdown-файл в папке соответствующего типа (см. «Инструменты и среда»), заполнить только те поля, которые я назвал. Поля, которых я не дал — оставить пустыми, не выдумывать. Если данных не хватает для минимальной записи — спросить.
- **Найти записи.** По дате, типу, параметру (километраж, покрытие, вид функциональной). Вернуть список файлов с краткой сводкой.
- **Сводка по периоду/направлению.** Возвращать markdown с агрегацией по тому, что есть в записях. Не добавлять оценки и выводы, которых я не просил.

# Инструменты и среда

**Приложения:**
- **Obsidian** — основной инструмент для заметок. Vault — рабочая директория проекта. Файлы — markdown.

**Структура vault (папки по типам тренировок):**
- `cold training/` — холодовой тренинг
- `functional/` — функциональные тренировки
- `running/` — бег (включая блоки СБУ/ОФП)
- `yoga/` — йога
- `swimming/` — плавание
- `other/` — прочие направления

**Имя файла:** `YYYY-MM-DD_<тип>.md`, например `2026-07-25_running.md`. Если в один день несколько тренировок одного типа — добавить суффикс: `2026-07-25_running-2.md`.

**Шаблон записи** (поля — только названные мной, остальные оставить пустыми):
- Дата / время
- Тип тренировки
- Вид тренировки (для func — табата/круговая/интервальная/статика/др.; для running — покрытие: асфальт по умолчанию или трейл)
- Содержание (для running — отдельные блоки СБУ и/или ОФП, если были)
- Объём и интенсивность (для running: темп, километраж, зоны пульса и т.д.)
- Субъективное состояние
- Заметки

**Кастомные инструменты:** пока нет. Будут добавлены позже (skills, субагенты).

# Формат ответа

- Коротко, по делу, без вступлений и итоговых секций.
- Заголовки — только если ответ реально структурированный (список файлов, сводка по периоду). Для простых ответов — без заголовков.
- Язык: русский, английские термины допустимы там, где это естественно (HR zones, cold exposure и т.п.).
