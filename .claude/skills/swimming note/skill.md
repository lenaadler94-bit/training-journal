# Плавание — навык разбора

Ты получаешь от пользователя свободное описание плавательной тренировки. Твоя задача — извлечь данные, при необходимости уточнить недостающее, сформировать структурированную заметку и сохранить её в папку `swimming/`.

## Порядок действий

1. **Извлечь данные** из описания пользователя по полям ниже.
2. **Проверить полноту.** Обязательное поле — дата. Если дата не названа — спросить. Место — обязательное поле, но если не названо — подставить «Бассейн» и не спрашивать. Остальные поля не спрашивать: нет информации — поле не выводить.
3. **Сформировать заметку** в формате markdown по шаблону.
4. **Сохранить файл** в папку `swimming/` с именем `YYYY-MM-DD_swimming.md`. Если файл за эту дату уже существует — добавить суффикс: `YYYY-MM-DD_swimming-2.md`, `YYYY-MM-DD_swimming-3.md` и т.д.

## Поля для извлечения

| Поле | Что содержит | Обязательное | Примечание |
|---|---|---|---|
| **Дата и время** | Дата и (опционально) время тренировки | Да (дата) | Если указана только дата — время не писать. Если дата не указана — спросить. Формат даты: `ГГГГ-ММ-ДД`, времени: `ЧЧ:ММ` |
| **Место** | Бассейн или открытая вода | Да | Если не названо — подставить «Бассейн», не спрашивать. Открытую воду указывать явно. |
| **Дистанция** | В метрах | Нет | Формат `N м` (например, `1000 м`). Если названо в километрах — перевести в метры (`1 км` → `1000 м`). Если не названа — не писать, не спрашивать. |
| **Стиль** | Стиль плавания | Нет | Варианты: Кроль, Брасс, Баттерфляй, На спине, Комплекс. Если названо несколько — записать через запятую в порядке упоминания. Если не упоминалось — поле не выводить. |
| **Продолжительность** | Длительность тренировки | Нет | Если указана — вывести в формате `N мин` (или `N ч M мин`). Если не названа — не писать, не спрашивать. |
| **Субъективное состояние** | Самочувствие, ощущения | Нет | Если упомянуто — вывести отдельным разделом. Иначе не выводить. |
| **Заметки** | Всё, что не вошло в основные поля | Нет | Если пользователь упомянул что-то помимо основных полей — включить сюда. |

## Шаблон заметки

```markdown
# Плавание. {{дата}}{{#время}} {{время}}{{/время}}

| | |
|---|---|
| **Место** | {{место}} |
{{#дистанция}}| **Дистанция** | {{дистанция}} |
{{/дистанция}}{{#стиль}}| **Стиль** | {{стиль}} |
{{/стиль}}{{#продолжительность}}| **Продолжительность** | {{продолжительность}} |
{{/продолжительность}}
{{#субъективное}}
## Субъективное состояние

{{субъективное}}
{{/субъективное}}{{#заметки}}
## Заметки

{{заметки}}
{{/заметки}}
```

**Ввод:** «Сегодня плавала 1000 метров кролем 30 минут».

>
> | | |
> |---|---|
> | **Место** | Бассейн |

> | **Стиль** | Кроль |

## Правила

- Язык заметки: русский.
- Не придумывать данные. Нет информации — поле не выводить (кроме даты: если не названа — спросить; и места: если не названо — «Бассейн»).
- Место: «Бассейн» по умолчанию, «Открытая вода» — если упомянуто явно.
- Стиль записывать с заглавной буквы: Кроль, Брасс, Баттерфляй, На спине, Комплекс.
- Дистанцию приводить к метрам: `1 км` → `1000 м`, `1.5 км` → `1500 м`.
- Продолжительность приводить к формату `N мин` (или `N ч M мин` при необходимости).
- Не добавлять эмодзи.
- Не писать вводные фразы перед заметкой. Сразу структура.
- Если в описании есть информация, не попадающая в стандартные поля — включить в «Заметки».
- При сохранении проверить, существует ли уже файл с таким именем. Если да — использовать суффикс.
