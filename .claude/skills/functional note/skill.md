# Функциональная тренировка — навык разбора

Ты получаешь от пользователя свободное описание функциональной тренировки. Твоя задача — извлечь данные, при необходимости уточнить недостающее, сформировать структурированную заметку и сохранить её в папку `functional/`.

## Порядок действий

1. **Извлечь данные** из описания пользователя по полям ниже.
2. **Проверить полноту.** Обязательные поля — дата и вид тренировки. Если по ним данных нет — задать конкретный вопрос. Не додумывать, не подставлять значения по умолчанию (кроме случаев, явно описанных в полях).
3. **Сформировать заметку** в формате markdown по шаблону.
4. **Сохранить файл** в папку `functional/` с именем `YYYY-MM-DD_functional.md`. Если файл за эту дату уже существует — добавить суффикс: `YYYY-MM-DD_functional-2.md`, `YYYY-MM-DD_functional-3.md` и т.д.

## Поля для извлечения

| Поле | Что содержит | Обязательное | Примечание |
|---|---|---|---|
| **Дата и время** | Дата и (опционально) время тренировки | Да (дата) | Если указана только дата — время не писать. Если дата не указана — спросить. Формат даты: `ГГГГ-ММ-ДД`, времени: `ЧЧ:ММ` |
| **Вид тренировки** | Конкретный вид | Да | Варианты: Табата, Круговая, Интервальная, Статика, другое. Если не назван — спросить. Записывать с заглавной буквы. |
| **Содержание** | Упражнения, блоки, структура | Нет | Если пользователь перечислил упражнения или блоки — вывести разделом с маркированным списком. Если не упомянуто — раздел не выводить. |
| **Объём и интенсивность** | Раунды, подходы, повторения, время работы/отдыха, длительность | Нет | Записывать только то, что назвал пользователь. Если названы раунды/подходы — указать. Если названо время работы и отдыха — указать. Если ничего из этого не упоминалось — раздел не выводить. |
| **Субъективное состояние** | Самочувствие, ощущения | Нет | Если упомянуто — вывести отдельным разделом. Иначе не выводить. |
| **Заметки** | Всё, что не вошло в основные поля | Нет | Если пользователь упомянул что-то помимо основных полей — включить сюда. |

## Шаблон заметки

```markdown
# Функциональная тренировка. {{дата}}{{#время}} {{время}}{{/время}}

| | |
|---|---|
| **Вид** | {{вид}}{{#доп_вид}} ({{доп_вид}}){{/доп_вид}} |

{{#содержание}}
## Содержание

{{содержание}}
{{/содержание}}{{#объём}}
## Объём и интенсивность

{{объём}}
{{/объём}}{{#субъективное}}
## Субъективное состояние

{{субъективное}}
{{/субъективное}}{{#заметки}}
## Заметки

{{заметки}}
{{/заметки}}
```

## Примеры

**Ввод:** «Сегодня табата, 8 раундов по 20 секунд работы 10 отдыха».

**Результат — но сначала уточнение:**

> — Какая дата?

**После уточнения (файл `functional/2026-07-26_functional.md`):**

> # Функциональная тренировка. 2026-07-26
>
> | | |
> |---|---|
> | **Вид** | Табата |
>
> ## Объём и интенсивность
>
> 8 раундов, 20 сек работа / 10 сек отдых

---

## Правила

- Язык заметки: русский.
- Не придумывать данные. Нет информации — спросить.
- Вид тренировки записывать с заглавной буквы: Табата, Круговая, Интервальная, Статика.
- Содержание — маркированным списком, каждый элемент с маленькой буквы.
- Не добавлять эмодзи.
- Не писать вводные фразы перед заметкой. Сразу структура.
- Если в описании есть информация, не попадающая в стандартные поля — включить в «Заметки».
- При сохранении проверить, существует ли уже файл с таким именем. Если да — использовать суффикс.
