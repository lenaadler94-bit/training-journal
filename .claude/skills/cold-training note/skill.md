# Холодовая тренировка — навык разбора

Ты получаешь от пользователя свободное описание холодовой тренировки. Твоя задача — извлечь данные, при необходимости уточнить недостающее, сформировать структурированную заметку и сохранить её в папку `Cold training/`.

## Порядок действий

1. **Извлечь данные** из описания пользователя по полям ниже.
2. **Проверить полноту.** Если по какому-то полю данных нет — задать конкретный вопрос. Не додумывать, не подставлять значения по умолчанию (кроме случаев, явно указанных в описании полей).
3. **Сформировать заметку** в формате markdown по шаблону.
4. **Сохранить файл** в папку `Cold training/` с именем `YYYY-MM-DD_cold training.md`. Если файл за эту дату уже существует — добавить суффикс: `YYYY-MM-DD_cold training-2.md`, `YYYY-MM-DD_cold training-3.md` и т.д.

## Поля для извлечения

| Поле | Что содержит | Обязательное | Примечание |
|---|---|---|---|
| **Дата и время** | Дата и время тренировки | Да | Если указана только дата — время не писать. Если не указано ничего — спросить. Формат даты: `ГГГГ-ММ-ДД`, времени: `ЧЧ:ММ` |
| **Локация** | Место тренировки | Да | Варианты: Купель, Гребной канал, другое. Если из описания неясно — спросить. |
| **Температура воздуха** | В градусах Цельсия | Да | Если не указана — спросить. |
| **Температура воды** | В градусах Цельсия | Да | Если не указана — спросить. |
| **Погружения** | Количество, время и/или расстояние каждого погружения | Да | Формат: нумерованный список. Если для погружения указано только количество без деталей — записать «окунание». Если указано время или расстояние — записать. |
| **Примечания** | Погода, самочувствие, сопутствующие обстоятельства | Нет | Если пользователь упомянул что-то помимо основных полей — включить сюда. |

## Шаблон заметки

```markdown
# Холодовая тренировка. {{дата}}{{#время}} {{время}}{{/время}}

| | |
|---|---|
| **Локация** | {{локация}} |
| **Температура воздуха** | {{t_воздуха}} °C |
| **Температура воды** | {{t_воды}} °C |

## Погружения

{{нумерованный_список_погружений}}

{{#примечания}}
## Примечания

{{примечания}}
{{/примечания}}
```

## Примеры

**Ввод:** «Сегодня была на Гребном канале, воздух +3, вода +1. Два заплыва по 50 метров».

**Результат (файл `Cold training/2026-06-15.md`):**

> # Холодовая тренировка. 2026-06-15
>
> | | |
> |---|---|
> | **Локация** | Гребной канал |
> | **Температура воздуха** | 3 °C |
> | **Температура воды** | 1 °C |
>
> ## Погружения
>
> 1. 50 м
> 2. 50 м

---

**Ввод:** «Вчера окунулась в купели, вода 4 градуса, на улице минус 8».

**Результат — но сначала уточнение:**

> — Сколько было погружений? И какая дата — вчера это какое число?

**После уточнения (файл `Cold training/2026-06-14.md`):**

> # Холодовая тренировка. 2026-06-14
>
> | | |
> |---|---|
> | **Локация** | Купель |
> | **Температура воздуха** | −8 °C |
> | **Температура воды** | 4 °C |
>
> ## Погружения
>
> 1. окунание

## Правила

- Язык заметки: русский.
- Не придумывать данные. Нет информации — спросить.
- Если пользователь указал температуру без знака — считать положительной. Минус — записывать с символом «−».
- Не добавлять эмодзи.
- Не писать вводные фразы перед заметкой. Сразу структура.
- Если в описании есть информация, не попадающая в стандартные поля — включить в «Примечания».
- При сохранении проверить, существует ли уже файл с таким именем. Если да — использовать суффикс.
