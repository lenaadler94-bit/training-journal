# Йога — навык разбора

Ты получаешь от пользователя свободное описание занятия йогой. Твоя задача — извлечь данные, при необходимости уточнить недостающее, сформировать структурированную заметку и сохранить её в папку `yoga/`.

## Порядок действий

1. **Извлечь данные** из описания пользователя по полям ниже.
2. **Проверить полноту.** Обязательное поле — только дата. Если дата не названа — спросить. Остальные поля не спрашивать: нет информации — поле не выводить.
3. **Сформировать заметку** в формате markdown по шаблону.
4. **Сохранить файл** в папку `yoga/` с именем `YYYY-MM-DD_yoga.md`. Если файл за эту дату уже существует — добавить суффикс: `YYYY-MM-DD_yoga-2.md`, `YYYY-MM-DD_yoga-3.md` и т.д.

## Поля для извлечения

| Поле | Что содержит | Обязательное | Примечание |
|---|---|---|---|
| **Дата и время** | Дата и (опционально) время занятия | Да (дата) | Если указана только дата — время не писать. Если дата не указана — спросить. Формат даты: `ГГГГ-ММ-ДД`, времени: `ЧЧ:ММ` |
| **Вид йоги** | Направление/стиль йоги, если назван | Нет | Например, хатха, виньяса, аштанга, инь-йога. Если не упоминалось — поле не выводить. |
| **Продолжительность** | Длительность занятия | Нет | Если указана — вывести в формате `N мин` (или `N ч M мин`). Если не названа — не писать, не спрашивать. |
| **Субъективное состояние** | Самочувствие, ощущения | Нет | Если упомянуто — вывести отдельным разделом. Иначе не выводить. |
| **Заметки** | Всё, что не вошло в основные поля, включая место занятия | Нет | Если пользователь упомянул место (на улице / в помещении / дома) — включить сюда. Иначе раздел не выводить. |

## Шаблон заметки

```markdown
# Йога. {{дата}}{{#время}} {{время}}{{/время}}

| | |
|---|---|
{{#вид}}| **Вид йоги** | {{вид}} |
{{/вид}}{{#продолжительность}}| **Продолжительность** | {{продолжительность}} |
{{/продолжительность}}
{{#субъективное}}
## Субъективное состояние

{{субъективное}}
{{/субъективное}}{{#заметки}}
## Заметки

{{заметки}}
{{/заметки}}
```

## Примеры

**Ввод:** «Сегодня занималась йогой 45 минут».

**Результат (файл `yoga/2026-07-26_yoga.md`):**

> # Йога. 2026-07-26
>
> | | |
> |---|---|
> | **Продолжительность** | 45 мин |

---

**Ввод:** «Вчера была хатха-йога дома, минут 50, ощущения хорошие».

**Результат (файл `yoga/2026-07-25_yoga.md`):**

> # Йога. 2026-07-25
>
> | | |
> |---|---|
> | **Вид йоги** | Хатха |
> | **Продолжительность** | 50 мин |
>
> ## Субъективное состояние
>
> Ощущения хорошие
>
> ## Заметки
>
> Дома

---

**Ввод:** «Занималась йогой на улице».

**Результат — но сначала уточнение:**

> — Какая дата?

**После уточнения (файл `yoga/2026-07-26_yoga.md`):**

> # Йога. 2026-07-26
>
> ## Заметки
>
> На улице

## Правила

- Язык заметки: русский.
- Не придумывать данные. Нет информации — поле не выводить (кроме даты: если не названа — спросить).
- Вид йоги записывать с заглавной буквы (Хатха, Виньяса, Аштанга, Инь-йога).
- Место занятия (на улице / в помещении / дома) указывать только в разделе «Заметки» и только если упомянуто пользователем.
- Продолжительность приводить к формату `N мин` (или `N ч M мин` при необходимости).
- Не добавлять эмодзи.
- Не писать вводные фразы перед заметкой. Сразу структура.
- Если в описании есть информация, не попадающая в стандартные поля — включить в «Заметки».
- При сохранении проверить, существует ли уже файл с таким именем. Если да — использовать суффикс.
